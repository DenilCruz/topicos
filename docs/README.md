# Documentación técnica

El informe técnico deberá cubrir:

1. Problema, tarea principal y categorías de incidentes.
2. Dataset: origen, licencia, fecha de obtención y análisis exploratorio.
3. Decisiones de NLP y comparaciones de stemming/lematización y n-gramas.
4. Modelos, línea base cuando corresponda, validación cruzada, métricas y análisis de errores.
5. Arquitectura e integración del pipeline con backend y frontend.
6. Limitaciones y declaración de uso de asistentes de IA.

Guardar también aquí las diapositivas y documentación adicional de la API. Este índice no sustituye al informe final.
